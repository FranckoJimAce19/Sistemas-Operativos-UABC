=========================================================
          INTERPRETE DE COMANDOS — Informacion
=========================================================
COMANDO                       DESCRIPCION
---------------------------------------------------------
join [archivo]                Muestra el contenido de un archivo
join> [archivo]               Crea un archivo en modo texto (termina con $)
copy [origen] [destino]       Copia un archivo a otro destino
del [archivo]                 Elimina un archivo
cd [directorio]               Cambia el directorio de trabajo
sdir                          Muestra el directorio actual
clear                         Limpia la pantalla
info                          Muestra esta ayuda
exit                          Termina el interprete
cmd1 | cmd2 | ...             Canaliza la salida de un comando hacia otro
---------------------------------------------------------
CPU SCHEDULING (Practica 6):
mkprocess [nombre] [burst]    Crea un proceso en la lista (ready queue)
lstprocss                     Muestra los procesos en la lista
fcfs                          Simula algoritmo First-Come First-Served
sjf                           Simula algoritmo Shortest Job First
rr                            Simula algoritmo Round-Robin (quantum=10 ut)
